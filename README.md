# Data Analytics Portfolio

An evolving portfolio of end-to-end data analytics case studies. Each project contains a clearly defined business question, documented data sources, reproducible analysis code, visualizations, and actionable recommendations.

## Featured projects

| Project | Business focus | Tools | Highlights |
|---|---|---|---|
| [Cyclistic Bike-Share](projects/cyclistic-divvy-bike-share-analysis/) | Convert casual riders into annual members | Python, pandas, matplotlib | 5.47M cleaned public trips; chunked pipeline; conversion experiments |
| [Bellabeat Fitness Tracker](projects/bellabeat-fitness-tracker-analysis/) | Translate smart-device behavior into marketing actions | Python, pandas, seaborn | Activity, sleep, and calorie behavior; targeted wellness recommendations |

## About this portfolio

The analyses use public or openly available data and are presented for portfolio and learning purposes. Recommendations are analytical hypotheses, not claims about individual users or causal effects.
