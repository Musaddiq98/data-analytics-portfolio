# Data Provenance and Schema Documentation

This directory contains clean daily summary extracts from the public FitBit Fitness Tracker dataset (Mobius / Kaggle):

- `dailyActivity_merged.csv`: 940 daily records across 33 distinct user IDs, capturing step counts, distances, active minute intensities, and caloric expenditure.
- `sleepDay_merged.csv`: 410 deduplicated daily records across 24 distinct user IDs, tracking sleep sessions, duration asleep, and total time in bed.

Granular minute-level and second-level raw tables (heart rate, minute calories, hourly intensities) are archived externally to maintain repository performance.
