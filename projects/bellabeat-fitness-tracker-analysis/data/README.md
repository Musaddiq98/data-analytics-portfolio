# Included data files

This portfolio copy keeps only the two small CSV files required by `scripts/analysis.py`:

- `dailyActivity_merged.csv`
- `sleepDay_merged.csv`

The full Fitbit Fitness Tracker Data source is available from the [Kaggle dataset](https://www.kaggle.com/datasets/arashnic/fitbit). Other raw exports are excluded from this repository to keep the portfolio lightweight.
